Connect your private Google Drive

One-time setup for the app owner. Your phone and computer must use the same OAuth client ID and Google account to access the same backups.

1. Create the Google Cloud project

Open Google Cloud Console, create or select a project, and enable the Google Drive API in APIs & Services → Library.

2. Configure Google Auth Platform

Set the app name to Charger Flow, choose your support email, and configure the audience. For a personal external app in Testing, add your own Google email as a test user. Under Data Access, add only https://www.googleapis.com/auth/drive.appdata. This lets the app access its own hidden app-data folder, without access to your ordinary Drive files.

3. Create a web OAuth client

In Google Auth Platform → Clients, create an OAuth client with application type Web application. Add this Authorized JavaScript origin for this repository:

https://omswenura.github.io

Do not include /Wenura-1/ in the origin. Optionally add http://localhost:3000 and http://127.0.0.1:3000 for development. This app uses Google's browser token model; no redirect URI or client secret is used in the app.

4. Add the client ID

Copy the client ID ending in .apps.googleusercontent.com. Paste it in Charger Flow → Your data & backups. Alternatively, put this public ID in public/config.js and publish again so you do not need to paste it on every device. Never put a client secret or access token in GitHub.

5. Connect and save

Tap Connect Google Drive and allow app-data access. Tap Save to Drive to create a private snapshot. On your other device, connect with the same Google account and client ID, choose a backup, then tap Restore from Drive. Confirm before replacing that device's record.

Each save creates a new snapshot, so another device's save is never overwritten. The app displays your 20 newest snapshots. This is manual backup and restore; it does not merge simultaneous edits. Access tokens stay in memory; reconnect when your session expires or you reopen the app. Google sign-in and cloud backups require internet access.

Install on your phone

Android: open your published HTTPS site in Chrome → menu → Add to home screen → Install.

iPhone: open it in Safari → Share → Add to Home Screen → Open as Web App (if shown) → Add.

After one successful online load, the checklist works offline. Closed-app scheduled reminders need a push backend and are not included. Device storage may be separate between the browser and installed app; use Drive or a JSON backup to transfer your record.

Troubleshooting

origin_mismatch: check the exact scheme and hostname in Authorized JavaScript origins. access_denied: add your email as a test user and check the audience. 403: enable the Drive API and allow app-data access. Popup blocked: allow Google sign-in popups and tap Connect again. Google Cloud configuration changes can take time to apply.

To revoke access, use your Google Account → Third-party connections. To remove app data, use Google Drive → Settings → Manage apps → Charger Flow → Delete hidden app data. Disconnect in this app only clears the current in-memory session; it keeps your backups.
